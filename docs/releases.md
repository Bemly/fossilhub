# FossilHub 发布历史

## 2026.08.30-beta.2 · 仓库短地址

- 浏览器仓库地址统一使用 `/repo/<slug>`，不再暴露磁盘文件的 `.fossil` 后缀。
- 旧的 `.fossil` 浏览器地址自动跳转到短地址，并保留查询参数和外部挂载前缀。
- 仓库文件名、平台登记名与 `/fossil/<slug>` 原生 clone/sync 通道保持不变，无需迁移数据。

## 2026.08.30-beta.1 · 双语账户入口

- 新增服务端渲染的简体中文/英文切换，优先使用语言 Cookie，并兼容浏览器 `Accept-Language`。
- 在首页、Explore、仓库和账户页面统一显示登录、注册、工作台、个人仓库及管理员入口。
- 补全登录、注册、工作台、个人仓库管理和管理员控制台的中文固定文案；仓库内容与用户资料保持原文。
- 语言回跳仅允许站内路径，语言 Cookie 使用 `SameSite=Lax`，不参与任何授权判断。
- 修正中文桌面导航换行，并使用版本化 CSS 地址绕过旧浏览器缓存。

## 2026.08.29-beta.1 · FossilHub 品牌标志

- 采用三枚化石叶片、中央 Hub 圆点和三角轮廓组成的正式横向 Logo，替换首页、Explore、仓库及账户页面顶部旧标志。
- 新增受控 PNG 静态路由、嵌套路径兼容、缓存版本和深色主题显示适配。
- 修正 Wapp 对 PNG 的二进制读取，保证响应字节与源码文件 SHA-256 完全一致。
- 2026-08-29 按用户明确授权直接在生产环境完成事务式部署和验证；保留两个即时回滚容器。

## 2026.08.28-beta.1 · 协作平台

- 新增应用自有的目录数据库和中央平台注册表。
- 新增 Argon2id 账号、不可预测会话、一次性表单挑战、公开资料、用户仪表盘、账号设置和仓库协作角色。
- 新增可恢复的仓库创建与归档流程，以及浏览器内文件、Wiki、Ticket 和 Forum 写入。
- 新增第一方历史、源码、文档、Ticket、Forum、分支、标签、统计和 ZIP 页面；Fossil CGI 仅保留公开 clone/sync 传输能力。
- 新增管理员后台、脱敏审计导出、安全健康面板、平台限制、近期密码校验和完整性隔离。
- 用真实的产品、政策、版本、隐私状态、安全和联系页面替换页脚占位链接，并支持安全维护通知和版本化浏览器资源。
- 2026-08-29 完成 NAS 隔离验收、事务式生产切换及上线后重启验证，当前运行于端口 6080。

## 0.2.0-beta.1 · 原生 Fossil 传输

- 新增隔离的 Tcl/Wapp/Althttpd 运行环境和原生 Fossil 仓库。
- 在 fnOS 上验证公开 clone/sync、持久化存储、重启行为和最初的三页地质风格界面。

## 0.1.2 · 稳定视觉基线

- 建立通过验收的 FossilHub 视觉原型和响应式布局。
- 作为早期稳定回滚镜像保留。
