# 中英文界面与账户入口实施计划

日期：2026-08-30

## 执行状态

- 国际化基础设施、全站账户入口和核心管理页面双语化已完成。
- 最终修订 `fe7824f` 已通过完整自动化测试、隔离 NAS 烟测和生产复验。
- 生产环境已事务式切换至 `2026.08.30-beta.1`；前一版本保留为停止态回滚容器。

## 背景与现状

FossilHub 已经具备中央注册、登录、退出、个人工作台、个人仓库管理和管理员控制台，相关路由包括 `/register`、`/login`、`/dashboard`、`/account/repositories` 和 `/admin`。当前主要问题不是后端功能缺失，而是公共首页、Explore 和仓库页仍沿用原型中的独立静态导航，账户入口没有贯穿公共页面，导致这些功能难以发现。

现有界面文案以英文为主，也没有稳定的语言偏好、服务端语言选择或无障碍语言标记。直接在浏览器端替换文案会造成首屏语言闪烁，并使无 JavaScript 页面、表单错误和服务端渲染片段继续显示英文，因此本次采用服务端渲染的中英文切换。

## 目标

- 提供简体中文与英文两种完整界面语言，默认依据语言 Cookie，其次依据浏览器 `Accept-Language`。
- 语言切换后保持当前页面，并通过同站点 Cookie 持久化，不写入平台注册数据库。
- 公共页、账户页和仓库页使用一致的账户入口：未登录显示“登录/注册”，已登录显示“工作台/我的仓库/退出”，管理员额外显示“管理”。
- 保持 FossilHub 现有地质勘探视觉系统、服务端渲染、挂载前缀适配、权限边界和一次性 CSRF 机制。
- 不修改原型目录 `reference/`，不改变 `.fossil` 仓库格式、平台数据库 schema 或生产数据。

## 实施顺序

### 第一步：国际化基础设施

1. 新增独立 Tcl 国际化模块，集中管理语言规范化、翻译表和安全回退。
2. 每个请求从 `fh_locale` Cookie 或 `Accept-Language` 解析 `zh-CN` / `en`。
3. 新增只接受 `POST` 的 `/locale` 路由，使用受限的回跳路径并设置 `SameSite=Lax` Cookie。
4. 让 HTML 的 `lang` 属性、页面标题、导航和维护提示服从当前语言。

### 第二步：统一全站入口

1. 抽取可复用的公共顶栏账户操作组件。
2. 首页、Explore、仓库页接入当前账户上下文。
3. 未登录状态显示登录和注册；已登录状态显示工作台、我的仓库和退出；管理员显示管理入口。
4. 在窄屏保留可横向滚动的操作区，避免恢复旧导航在 390 px 下被完全隐藏的问题。

### 第三步：核心页面双语化

优先覆盖用户完成主要任务所经过的页面：

1. 首页、Explore、仓库一级导航和空状态。
2. 登录、注册、工作台、个人仓库列表与仓库设置。
3. 管理员概览、用户、仓库、审计、健康、设置和重新认证页面。
4. 公共信息页和错误页。

仓库内容、提交说明、Wiki、Ticket 和 Forum 正文属于用户数据，只做转义，不翻译。

### 第四步：验证与回归

1. 为语言解析、Cookie、回跳校验和 `/locale` 路由补充单元测试。
2. 为匿名、普通用户和管理员的导航入口补充视图测试。
3. 验证中文和英文 SSR 页面均包含正确 `lang`、标题、表单动作和权限入口。
4. 运行 Tcl 9.1b0 全套测试、两个 JavaScript 语法检查和 `live-script.test.js`。
5. 浏览器验证桌面、913 px 和 390 × 844，覆盖直接 LAN 路径及模拟挂载前缀。

### 第五步：发布准备

1. 变更静态 CSS/JavaScript 时更新资源版本，避免一小时缓存继续使用旧文件。
2. 同步 `README.md`、`PLAN.md`、`docs/operations.md` 和对应验收记录。
3. 仅从完整已提交修订创建 NAS 构建输入；生产切换必须另行执行完整发布门禁。

## 设计约束

本次不重新设计页面。语言与账户操作被视为同一条“地层工具带”：语言是站点级偏好，账户操作是身份与权限状态。它们沿用现有字体、细边框、矿物色和紧凑单色图标，不引入独立的通用下拉导航或新的视觉主题。

中文界面继续使用现有 IBM Plex 字体栈，并加入系统中文无衬线回退，避免为新增功能扩大远程字体依赖。英文品牌名、Fossil、Wiki、Ticket、Forum、check-in、slug 和精确命令保持原文。

## 风险与回退

- 若翻译键缺失，必须安全回退到英文键值，页面不能因缺失翻译而失败。
- 语言 Cookie 不含身份或权限信息，不得作为授权判断依据。
- `/locale` 回跳只能接受站内路径；无效值统一回到首页，防止开放重定向。
- 管理员入口只对中央角色为 `administrator` 的已登录用户渲染；后端现有权限检查仍是最终边界。
- 每个阶段单独提交；出现回归时可以按阶段回退，不触碰 NAS 持久化数据。

## 完成标准

- 匿名用户从任一主要公共页面都能发现登录、注册和语言切换。
- 普通用户从任一主要页面都能进入工作台和个人仓库管理。
- 管理员从任一主要页面都能进入 `/admin`。
- 中文与英文切换在刷新、直接访问子页面和挂载前缀下保持有效。
- 所有页面仍为完整 SSR HTML；禁用 JavaScript 时认证、导航和所选语言仍然可用。
- 原有认证、仓库权限、Fossil 只读查询、写锁、CSRF、clone/sync 和私有仓库隐藏行为无回归。
